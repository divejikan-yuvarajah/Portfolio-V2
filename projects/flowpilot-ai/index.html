01 · CONTEXT

The problem

Small businesses often use separate bank apps and spreadsheets to follow cash position, overdue invoices and short-term risk. FlowPilot's project brief frames the problem as bringing those signals into one financial workflow for Sri Lankan SMEs.

Project goals

  • Bring cash position, runway and receivables into one view.
  • Help an owner review overdue-payment risk and prepare a follow-up.
  • Explore cash-flow scenarios before a short-term decision.

03 · TECHNICAL VIEW

Architecture & implementation

The project README describes a Next.js application with server routes, Supabase/PostgreSQL and external financial/AI services. This is a summary of the team documentation, not a code-level audit of every path.

  • A user opens the financial overview and selects a receivables or scenario workflow.
  • The application server coordinates data access and documented analysis services.
  • Supabase/PostgreSQL is listed for application records and authentication; external banking connections are described as sandbox integrations.
  • The interface presents the resulting financial context and suggested follow-up for human review.
  • Next.js (README-listed)
  • TypeScript (README-listed)

The README distinguishes live sandbox API calls from simulated payment rails. No production banking connection or named model provider is claimed here.
